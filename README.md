# **Unminal Engine**

### **> !The project is still in development! <**

The project may contain unoptimized or experimental code due to its early stage of development. If you find an opportunity to improve the code, feel free to open an [Issue](https://github.com/dovintc-off/Unminal-Engine/issues)

The engine **doesn't dictate rules**; it hands you the tools to **bring your vision** to life.
A simple, open-source 3D game engine built from scratch in C# using OpenTK.

# Tech Stack
**Language:** C# (.NET 10.0)
**Graphics API:** OpenGL 3.3 (via OpenTK 4.9.4)
**IDE:** Visual Studio Code / Visual Studio 2022

# Prerequisites
[.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0) or later.
Graphics drivers supporting OpenGL 3.3+.

# How to run / build
```bash
# Clone the repository
git clone https://github.com/dovintc-off/Unminal-Engine.git
cd Unminal-Engine
# Run
dotnet run -c Release
# or build 
# dotnet build -c Release
```
